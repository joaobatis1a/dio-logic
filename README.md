# Dio Logic

**Atividades de lógica de programação** · JavaScript

[![License: MIT](https://img.shields.io/badge/license-MIT-22C55E?style=flat-square)](LICENSE)

Repositório com atividades e desafios desenvolvidos durante meus estudos de lógica de programação com JavaScript na [DIO](https://www.dio.me/).

## Projetos

- `RankingGame`, ranking de jogadores
- `RankingMyHero`, ranking de heróis
- `MyHero`, cadastro e exibição de herói

## Stack

- **JavaScript**
- **Node.js**

## Como rodar

```bash
git clone https://github.com/joaobatis1a/dio-logic.git
cd dio-logic/ProgramLogic
node MyHero.js
```

Troque `MyHero.js` pelo arquivo que quiser rodar (`RankingGame.js` ou `RankingMyHero.js`).
