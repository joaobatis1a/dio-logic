# DioActivities

Repositório com atividades e desafios desenvolvidos durante meus estudos na DIO.

## 📚 Projetos

- RankingGame
- RankingMyHero
- MyHero

## 🚀 Tecnologias

- JavaScript
- Node.js
- Git & GitHub

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/seuusuario/DioActivities.git
```

Entre na pasta do projeto:

```bash
cd DioActivities
```

Execute o arquivo JavaScript com Node.js:

```bash
node nomeDoArquivo.js
```

Exemplo:

```bash
node MyHero.js
```
